# Demonstration video plan

Target length: 75–90 seconds. Record at 1440 × 900 in a GPU-backed browser, with the cursor visible and system notifications off. No music needed; short captions carry the narrative.

| Time | Shot           | Action                                                                          | Caption                                                                     |
| ---- | -------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 0:00 | Home           | Slow scroll from hero to the collection grid.                                   | Six Egyptian coffins, read where the words were written.                    |
| 0:08 | Home → exhibit | Click Psamtik-Seneb. Hold on the progress bar, then the model appearing.        | Compressed geometry and preview textures first; full resolution streams in. |
| 0:16 | Exhibit        | Orbit slowly. Hover two regions so their labels appear.                         | 94 regions, each linked to a scholarly entry.                               |
| 0:24 | Exhibit        | Click the central columns. Camera flies in; the panel jumps to the inscription. | Click the surface, read the text.                                           |
| 0:32 | Panel          | Point at the hieroglyphs, transliteration and translation lines.                | Hieroglyphs, transliteration, translation.                                  |
| 0:38 | Panel → model  | Click the word ꜣḫt; press "Show on object"; then "Next location".               | Words lead to every place they occur.                                       |
| 0:50 | Light panel    | Press L. Choose Raking left, then drag the direction slider slowly.             | Raking light across the scanned geometry.                                   |
| 1:02 | Views          | Press 2 (back), 3 (left), R (reset).                                            | Keyboard-first: every action has a shortcut.                                |
| 1:08 | Copy link      | Press Copy link; open it in a new tab; the same region and light appear.        | Every view is shareable.                                                    |
| 1:15 | Search         | Search "Osiris"; filter Inscriptions; open a result on another coffin.          | Search 314 entries across the collection.                                   |
| 1:25 | Phone          | The same exhibit on a phone.                                                    | Works on phones and tablets.                                                |

Close on the repository README with the architecture diagram.
